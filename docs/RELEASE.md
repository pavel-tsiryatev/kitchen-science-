# Сборки и релизы Android

## Какие сборки бывают

| Событие | Что собирается | Где взять |
|---|---|---|
| Пуш в `main` | debug APK | Релиз «Тестовая сборка (main)» (тег `dev`, обновляется) и артефакт в Actions |
| Pull request | debug APK | Артефакт в Actions (проверка, что всё собирается) |
| Тег `v1.2.3` | подписанные release APK и AAB | Релиз «Кухня 1.2.3» |

`versionCode` = номер запуска GitHub Actions (растёт сам), `versionName` = версия из тега
(для тестовых сборок — `версия-из-package.json-dev.N`).

## Первая настройка подписи (один раз)

1. На своём компьютере с JDK: `./scripts/create-keystore.sh`
2. Добавьте четыре секрета, которые напечатает скрипт, в
   GitHub → Settings → Secrets and variables → Actions.
3. Сохраните `kuhnya-release.jks` и пароль в надёжном месте (менеджер паролей, облако).
   **Без этого ключа нельзя выпускать обновления приложения в магазинах.**
   В репозиторий файл ключа не добавляйте.

## Выпуск версии

```bash
git checkout main && git pull
git tag v1.1.0
git push origin v1.1.0
```

Через несколько минут появится релиз с `kuhnya-1.1.0.apk` (установка напрямую / RuStore)
и `kuhnya-1.1.0.aab` (Google Play).

> Тестовые (debug) и релизные сборки подписаны разными ключами. Чтобы перейти с одной на
> другую на телефоне, приложение придётся удалить и установить заново (сначала сделайте
> резервную копию в настройках).

## Локальная сборка

Нужны Android SDK и JDK 21.

```bash
npm run build
node scripts/prepare-android.mjs   # создаёт android/, иконки, версию, синхронизирует
cd android && ./gradlew assembleDebug
```

Иконка и заставка генерируются из `assets/` (исходник логотипа — `assets/logo.svg`).
